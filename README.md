# 스마트 분리수거 시스템

카메라로 재활용 폐기물을 인식해 해당 수거함 뚜껑만 열어주는 시스템입니다.
**데이터셋 구축 → YOLOv8 학습 → 라즈베리파이 탑재 → 센서·구동부 제어**까지 한 흐름으로 만들었습니다.

> 전북대학교 융합기술공학부 캡스톤 (2025.09 ~ 2025.12, 팀 프로젝트)
> 담당: 데이터셋 구축·모델 학습·엣지 배포·제어 회로 및 제어 코드
>
> 당시 진행한 프로젝트를 코드 중심으로 정리해 공개한 저장소입니다.

---

## 1. 문제

분리배출은 버리는 사람이 매번 재질을 판단해야 하고, 잘못 넣으면 재활용이 어려워집니다.
**투입하려는 물건을 카메라가 먼저 인식해, 맞는 수거함만 열리게** 하면 판단을 사람이 하지 않아도 됩니다.

## 2. 데이터셋

| 항목 | 내용 |
|---|---|
| 규모 | 1,910장 |
| 클래스 | `Can` · `Glass` · `Plastic` (3종) |
| 라벨링 | Roboflow |
| 버전 | v3 (라벨을 고쳐가며 재구성) |

**학습셋과 평가셋의 출처를 다르게 구성했습니다.**

| 분할 | 출처 |
|---|---|
| Train | 직접 녹화한 영상에서 프레임 추출 |
| Valid / Test | 웹에서 수집한 별개의 사진 |

영상에서 뽑은 프레임은 서로 매우 비슷해서, 같은 영상의 프레임이 학습셋과 평가셋에 나뉘어 들어가면 성능이 실제보다 좋게 나옵니다.
평가셋을 **다른 출처의 이미지로 채워** 배경·조명·각도가 달라져도 인식되는지를 확인했습니다.

> ⚠️ 원본 이미지는 출처가 섞여 있어(웹 수집 + 직접 촬영·녹화) 저작권 문제로 이 저장소에 포함하지 않습니다. 라벨링 과정과 학습·제어 코드만 공개합니다.

**전수 수작업 대신 자동 라벨링을 썼습니다.**

1. 일부(약 200장)를 직접 라벨링해 기준을 만들고
2. 그 라벨을 바탕으로 나머지를 **자동 라벨링으로 확장**한 뒤
3. **잘못 붙은 라벨만 골라 수정**해 최종 데이터셋을 구성했습니다

전부 손으로 했다면 학습을 시작하지도 못했을 분량이라, **라벨 비용을 줄이면서 품질은 검수로 확보하는 방식**을 택했습니다.

## 3. 모델

```
YOLOv8n (사전학습) → 위 데이터셋으로 학습 → tflite 변환 → 라즈베리파이 탑재
```

- 학습: `train/train_yolov8.py` (Colab에서 실행, imgsz 416 / batch 8)
- 배포: 라즈베리파이에서 돌리기 위해 `model.export(format="tflite")`로 변환

## 4. 동작 로직

`device/trash_detect.py`

| 단계 | 처리 |
|---|---|
| 촬영 | Picamera2로 프레임 취득 (640×480), OpenCV로 색공간 변환 |
| 인식 | YOLO로 `can` / `glass` / `plastic` 검출 |
| **오검출 억제** | **3초 이상 연속으로 같은 클래스가 검출돼야** 동작 (`is_detected_for`) |
| 적재량 확인 | 초음파 센서로 거리 측정 → **10cm 미만이면 가득 참으로 보고 열지 않고 경고 LED** |
| 개방 | 서보모터 PWM 제어로 해당 수거함 뚜껑만 90도 개방 |
| 닫기 | 소리 센서로 투입을 확인하면 뚜껑을 닫고 완료음 재생 |

한 프레임만 보고 뚜껑을 열면 오검출에 그대로 반응하게 되어, **연속 검출 조건**을 두어 걸러냈습니다.
가득 찬 통은 열어도 소용이 없으므로 **열기 전에 적재량을 먼저 확인**합니다.

## 5. 하드웨어

- 라즈베리파이 + 카메라 모듈
- 수거함 3개(캔·유리·플라스틱)마다: 서보모터 · 초음파 센서 · 소리 센서 · 상태 LED · 만재 LED
- 제어 회로는 브레드보드로 구성 (`docs/wiring.jpg`, `docs/block_diagram.png`)

## 6. 사용자 앱

- Firebase 인증 기반 로그인 화면 (`app/login.html`)
- 라즈베리파이가 Firestore를 구독해 로그인한 사용자를 인식 (`app/pi_listener.py`)
- 파이 쪽 수신 서버 (`app/pi_server.py`)

## 7. 폴더 구성

```
train/    train_yolov8.py      데이터셋 다운로드 → 학습 → tflite 변환
device/   trash_detect.py      메인 (검출 + 센서 + 구동부 제어)
          test_servo.py        서보 단독 테스트
          test_ultrasonic.py   초음파 단독 테스트
          labels.txt           클래스 정의
app/      login.html           로그인 화면
          pi_listener.py       Firestore 구독
          pi_server.py         파이 수신 서버
docs/     block_diagram.png    시스템 블록도
          flow_diagram.png     동작 흐름도
          roboflow_dataset.png 데이터셋 생성 화면
          wiring.jpg           배선
```

## 8. 실행

```bash
# 학습 (Colab)
export ROBOFLOW_API_KEY="발급받은 키"
python train/train_yolov8.py

# 라즈베리파이
python device/trash_detect.py
```

> 이 저장소에는 **API 키, Firebase 서비스 계정 키, 학습된 가중치, 데이터셋이 포함되어 있지 않습니다.**
> `app/login.html`의 Firebase 설정값과 `app/pi_listener.py`가 읽는 `serviceAccountKey.json`은 직접 채워야 합니다.
